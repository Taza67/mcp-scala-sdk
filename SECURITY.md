# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| `main`  | yes       |

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, use [GitHub Security Advisories](https://github.com/taza67/mcp-scala-sdk/security/advisories/new) (preferred) or contact the maintainer privately through GitHub.

Include:

- A description of the issue and potential impact
- Steps to reproduce, if applicable
- Affected modules or versions

You should receive an acknowledgment within a reasonable time. We will work with you to understand and address the issue before any public disclosure.
